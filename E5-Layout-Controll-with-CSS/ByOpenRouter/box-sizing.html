CSS box-sizing

box-sizing controls how the browser calculates the total size of an element.

1. box-sizing: content-box; (default)

Width and height apply only to the content area. Padding and border are added on top, making the element larger than the width you set.

I am 300px wide on content, but my total width is 350px (300 + 20 + 20 + 5 + 5).

2. box-sizing: border-box;

Width and height include padding and border, so the visible box matches the number you set.

I am exactly 300px wide total. Padding and border are counted inside.

Tip: Most developers use * { box-sizing: border-box; } to make layouts easier.
