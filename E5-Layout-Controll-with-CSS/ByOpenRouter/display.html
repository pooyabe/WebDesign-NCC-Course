CSS display

The display property decides how an element is placed on the page and how it interacts with nearby elements.

1. display: block;

Block elements take up the full width and start on a new line.

I am an inline element forced to be block. I also take the whole line.

2. display: inline;

Inline elements sit next to each other inside a line and ignore width/height.
