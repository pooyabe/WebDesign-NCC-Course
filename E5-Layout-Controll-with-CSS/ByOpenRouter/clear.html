CSS clear

The clear property tells an element: "Do not allow floated elements beside me on the specified side."

1. clear: left;

Float Left

This paragraph wraps around the red box.

I have clear: left;, so I move below the red floated box instead of wrapping beside it.

2. clear: right;

Float Right

This paragraph wraps around the blue box.

I have clear: right;, so I drop below the blue floated box on the right.

3. clear: both;

Float Left
Float Right

I have clear: both;, so I start below all floated elements, both on the left and the right.

Remember: Use clear when you want content to stop wrapping around floats and start on a fresh line.
