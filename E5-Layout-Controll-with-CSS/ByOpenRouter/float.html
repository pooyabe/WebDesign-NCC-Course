CSS float

float moves an element to the left or right and lets text wrap around it. It was originally made for magazine-style text wrapping.

1. float: left;

Float Left

This text wraps around the red box because the box is floated to the left. The inline content of this paragraph moves to the right side of the floated element.

2. float: right;

Float Right

This text wraps around the blue box because the box is floated to the right. Notice how the paragraph content flows on the left side of the floated box.

3. float: none; (default)

I am not floated.

Without floating, this element sits in the normal document flow and the paragraph appears below it instead of wrapping around it.

Note: Modern layouts usually use display: flex or display: grid instead of floats.
