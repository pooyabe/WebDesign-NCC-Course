## 0. Normal Flow
Normal Flow — جریان عادی صفحه

در حالت عادی، مرورگر عناصر HTML را بر اساس نوع نمایش و ترتیب قرارگیری آن‌ها در کد HTML، در صفحه مرتب می‌کند. به این رفتار Normal Flow یا جریان عادی صفحه می‌گوییم.

یعنی مرورگر بدون اینکه ما موقعیت خاصی برای عناصر تعیین کنیم، خودش آن‌ها را طبق قواعد CSS کنار هم یا زیر هم قرار می‌دهد.
رفتار عناصر در جریان عادی

    عناصر block معمولاً از خط جدید شروع می‌شوند و زیر عناصر Block قبلی قرار می‌گیرند.

    عناصر inline در امتداد متن و کنار یکدیگر قرار می‌گیرند.

    ترتیب عناصر در صفحه معمولاً از ترتیب آن‌ها در HTML پیروی می‌کند.

ارتباط با Position و Float

    static: عنصر در جریان عادی باقی می‌ماند.

    relative: عنصر جابه‌جا می‌شود، اما فضای اولیه آن در جریان عادی حفظ می‌شود.

    absolute: عنصر از جریان عادی خارج می‌شود و فضای اولیه‌اش را اشغال نمی‌کند.

    fixed: مانند Absolute از جریان عادی خارج می‌شود و نسبت به پنجره مرورگر موقعیت می‌گیرد.

    float: عنصر از جریان عادی خارج می‌شود، اما برخلاف Absolute، محتوای اطراف می‌تواند در فضای کنارش جریان پیدا کند.


## ۱. Box Model

در CSS هر عنصر HTML مانند یک جعبه در نظر گرفته می‌شود. مرورگر برای محاسبه اندازه و فاصله عناصر از مدلی به نام Box Model استفاده می‌کند.

این جعبه چهار بخش دارد:

- **Content:** محتوای اصلی عنصر؛ مثل متن، تصویر یا عناصر داخلی. عرض و ارتفاعی که با `width` و `height` تعیین می‌کنیم، در حالت پیش‌فرض مربوط به همین قسمت است.
    
- **Padding:** فضای خالی بین محتوا و کادر عنصر. برای ایجاد فاصله داخلی استفاده می‌شود. رنگ پس‌زمینه عنصر نیز این قسمت را پوشش می‌دهد.
    
- **Border:** کادری که دور Content و Padding قرار می‌گیرد. می‌توان ضخامت، رنگ و نوع آن را تعیین کرد.
    
- **Margin:** فاصله بیرونی عنصر از عناصر اطراف. برای ایجاد فاصله بین جعبه‌ها استفاده می‌شود و جزئی از کادر قابل مشاهده عنصر نیست.
    

ترتیب اجزا از داخل به خارج:

`Content → Padding → Border → Margin`

### ویژگی box-sizing

نحوه محاسبه عرض و ارتفاع نهایی عنصر را مشخص می‌کند.

- `content-box`: حالت پیش‌فرض. مقدار width فقط عرض محتواست و Padding و Border به آن اضافه می‌شوند.
    
- `border-box`: مقدار width شامل Content، Padding و Border است؛ بنابراین اندازه نهایی قابل پیش‌بینی‌تر می‌شود.
    

روش رایج در پروژه‌ها:

```
* {
    box-sizing: border-box;
}
```

## ۲. ویژگی Display

نحوه نمایش و قرارگیری عنصر در صفحه را مشخص می‌کند.

- `block`: از خط جدید شروع می‌شود و به‌طور پیش‌فرض تمام عرض در دسترس را اشغال می‌کند. می‌توان width و height تعیین کرد.
    
- `inline`: در جریان متن قرار می‌گیرد و کنار عناصر دیگر می‌آید. width و height معمولاً روی آن اثر ندارند.
    
- `inline-block`: مانند inline کنار عناصر دیگر قرار می‌گیرد، اما می‌توان برای آن width و height تعیین کرد.
    

مثال‌های آشنا:

- `div`: به‌طور پیش‌فرض block
    
- `span`: به‌طور پیش‌فرض inline
    

## ۳. مرور Float

برای شناور کردن عنصر به سمت چپ یا راست استفاده می‌شود.

- `float: left`
    
- `float: right`
    
- `float: none`
    

عنصر Float شده از جریان عادی صفحه خارج می‌شود و محتوای اطراف می‌تواند در فضای باقی‌مانده کنار آن قرار بگیرد.

**نکته:** Float ابزار اصلی طراحی چیدمان‌های مدرن نیست؛ فعلاً برای شناخت رفتار آن و درک ساختار صفحات قدیمی‌تر از آن استفاده می‌کنیم.

## ۴. ویژگی Clear

برای جلوگیری از قرار گرفتن عناصر بعدی در کنار عناصر Float شده استفاده می‌شود.

- `clear: left`: عبور از شناورهای سمت چپ
    
- `clear: right`: عبور از شناورهای سمت راست
    
- `clear: both`: عبور از شناورهای هر دو سمت
    

مثال:

```
footer {
    clear: both;
}
```

برای نگه داشتن ارتفاع والد متناسب با عناصر Float شده، می‌توان از روش‌هایی مثل Clearfix نیز استفاده کرد.

## ۵. ویژگی Position

نحوه موقعیت‌گیری عنصر در صفحه را مشخص می‌کند.

- `static`: حالت پیش‌فرض؛ عنصر در جریان عادی صفحه قرار دارد و ویژگی‌های top و right و bottom و left روی آن اثر ندارند.
    
- `relative`: عنصر نسبت به موقعیت اولیه خودش جابه‌جا می‌شود؛ فضای اولیه آن در صفحه حفظ می‌شود.
    
- `absolute`: عنصر از جریان عادی صفحه خارج می‌شود و نسبت به نزدیک‌ترین والد دارای position غیر از static موقعیت می‌گیرد.
    

ویژگی‌های موقعیت‌دهی:

- `top`
    
- `right`
    
- `bottom`
    
- `left`
    

**نکته مهم:** معمولاً به والد عنصر absolute مقدار `position: relative` می‌دهیم تا همان والد مرجع موقعیت‌گیری فرزند باشد.

## ۶. تمرین عملی

- ساخت چند کارت اطلاعاتی در یک بخش از صفحه
    
- تعیین ابعاد کارت‌ها
    
- تنظیم فاصله داخلی و خارجی
    
- تغییر رفتار عناصر با display
    
- استفاده از float برای کنار هم قرار دادن کارت‌ها
    
- بررسی مشکل قرار گرفتن Footer کنار عناصر Float شده
    
- حل مشکل با clear
    
- آزمایش position: relative و absolute با یک مثال ساده
