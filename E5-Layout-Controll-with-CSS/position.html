Position در CSS

۱. position: static

حالت پیش‌فرض؛ top و right و bottom و left روی آن اثر ندارند.

static
عنصر بعدی

۲. position: relative

نسبت به جای اولیه خودش جابه‌جا می‌شود، اما فضای اولیه‌اش حفظ می‌شود.

عادی
relative
عنصر بعدی

۳. position: absolute

از جریان عادی خارج می‌شود و نسبت به نزدیک‌ترین والد دارای position غیر از static موقعیت می‌گیرد.

والد با position: relative
absolute

معمولاً به والد position: relative می‌دهیم تا مرجع موقعیت‌گیری فرزند باشد.
